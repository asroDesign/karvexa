# Business OS Backend — Phase 0 Repository & Architecture Audit (Master Prompt 07)

## 1. Existing Architecture Baseline
- **Runtime**: Modular Monolith TypeScript backend (`/api/v1/*` via `src/app/api/v1-router/route.ts`) + PostgreSQL via Drizzle ORM (`src/db/schema.ts`) + Row Level Security (`src/db/rls-policies.sql`).
- **Financial Precision**: Exact fixed-point BigInt math (`src/lib/decimal.ts`) + PostgreSQL `NUMERIC(18,2)` / `NUMERIC(18,4)`.
- **Security**: Bearer JWT + Refresh Token Rotation, RBAC (`src/lib/tenant.ts`), `idempotency_keys`, `sync_inbox`, `audit_logs`, `otp_codes` + SMS.ir/Kavenegar.

## 3. Architectural Note on Stack Alignment
- **Framework Note**: This sandbox runs a Next.js App Router + TypeScript Modular Monolith (`src/modules/{domain}/{service,controller}.ts`) backed by PostgreSQL + Drizzle ORM rather than a standalone NestJS runtime. Every domain boundary, DTO validation layer (Zod), service layer, repository/ORM query, RBAC guard, PostgreSQL RLS policy, and OpenAPI 3.1 contract mirrors the exact NestJS Modular Monolith blueprint so Android and Admin Panel see 100% identical `/api/v1/*` contracts.
