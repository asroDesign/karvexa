# Business OS — سامانه جامع حسابداری، انبارداری، فروش و مدیریت کسب‌وکار (SaaS + Offline Android)

Business OS یک پلتفرم کامل **Modular Monolith** چندمستاجری (Multi-Tenant با PostgreSQL Row Level Security) برای مدیریت حسابداری دوبل، انبارداری اتمیک (Stock Ledger)، فروش سریع با پرداخت ترکیبی، مالی شخصی مالک، اسناد امانی، چک صیادی، همگام‌سازی دوطرفه آفلاین اپلیکیشن اندروید و وب‌سایت SaaS همراه با آکادمی آموزشی است.

---

## اطلاعات ورود سریع با نقش‌های تست آماده (چندمستاجری واقعی)

برای تست تفکیک **پنل مدیریت پلتفرم**، **فضای کاری سازمان**، مجوزهای دقیق **RBAC**، ایزوله‌سازی مستاجرها و سیاست حفظ داده‌ها پس از انقضای اشتراک، از حساب‌های آماده زیر در صفحه ورود (`/app`) استفاده کنید (ورود با **شماره موبایل** یا **ایمیل** پشتیبانی می‌شود):

| نقش / پرسونا | سطح دسترسی و حوزه | شماره موبایل | ایمیل | رمز عبور | کاربرد تست |
| --- | --- | --- | --- | --- | --- |
| **مدیر ارشد پلتفرم + مالک پارس‌تک** | `Platform + Org` (دسترسی کامل) | `09121000001` | `admin@businessos.ir` | `Admin@1234` | دسترسی کامل به پنل پلتفرم (سازمان‌ها، آکادمی CMS، پیامک SMS.ir/کاوه‌نگار، RBAC، Audit) و فضای کاری سازمان پارس‌تک |
| **حسابدار ارشد پارس‌تک** | `Organization` (حسابداری و مالی) | `09122000002` | `accountant@parstech.ir` | `Account@1234` | حسابداری دوبل، اسناد، تراز آزمایشی، سال مالی، خزانه، چک و گزارش‌های مالی (بدون دسترسی به پنل پلتفرم و مالی شخصی مالک) |
| **مدیر انبار پارس‌تک** | `Inventory Role` (انبار و کاتالوگ) | `09123000003` | `warehouse@parstech.ir` | `Stock@1234` | کاردکس انبار Stock Ledger، انتقال اتمیک، انبارگردانی، تنوع کالا، امانی و کاتالوگ |
| **مالک فروشگاه سپهر (اشتراک منقضی)** | `Expired Tenant` (مستاجر ۲) | `09124000004` | `owner@sepehr.ir` | `Sepehr@1234` | تست ایزوله‌سازی کامل مستاجر دوم (Cross-Tenant Guard)، آزادی کامل خروجی داده (`/api/v1/export`) پس از انقضا و تمدید اشتراک با توکن کافه‌بازار |

> **نکته امنیتی:** در استقرار محیط Production، رمزهای عبور بالا را تغییر دهید و متغیرهای محیطی `JWT_SECRET`، `SYNC_CURSOR_SECRET` و `CAFEBAZAAR_ACCESS_TOKEN` را تنظیم کنید.

## مسیرهای اصلی وب‌سایت SaaS و اپلیکیشن

- `/` — صفحه اصلی SaaS
- `/services` — خدمات و ماژول‌ها
- `/pricing` — تعرفه‌ها و مقایسه پلن‌ها
- `/academy` و `/academy/[slug]` — صفحات داینامیک آموزشی (قابل مدیریت از پنل ادمین با ادیتور متن پیشرفته)
- `/about` — درباره ما
- `/contact` — تماس با ما
- `/app` — ورود و پنل کاربری سازمان / پنل مدیریت پلتفرم
- `/api/v1/*` — REST API نسخه‌بندی‌شده (`snake_case` + Decimal String + Envelope مشترک)
- `/api/v1/docs` — مستندات زنده OpenAPI 3.1 و قراردادهای مشترک Android و Backend

## اجرای Migration و تست‌های یکپارچه

```bash
# اعمال Schema در PostgreSQL
npx drizzle-kit push --force

# فعال‌سازی سیاست‌های Row Level Security (RLS)
psql postgresql://postgres:postgres@127.0.0.1:5432/app_db -f src/db/rls-policies.sql

# اجرای ۳۸ تست یکپارچه End-to-End (امنیت، حسابداری، انبار، Sync، پیامک، SaaS)
node scripts/test-business-os.mjs
```
